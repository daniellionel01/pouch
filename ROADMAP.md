# Roadmap

Pouch is a side project and v1 is meant to be the whole thing. This file
collects ideas that were deliberately left out, in case someone wants them.

- Clipboard history
- Notch UI
- Shake-to-summon (shake the cursor while dragging to show the shelf)
- Multiple shelves
- Cloud sync / upload-and-share links
- GitHub Actions release workflow (zipped `.app` on tag) and a Homebrew cask
