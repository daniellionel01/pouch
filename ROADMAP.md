# Roadmap

Pouch is a side project and v1 is meant to be the whole thing. These ideas
were deliberately left out; they're here in case someone wants them.

## Release plumbing
- GitHub Actions workflow that builds a zipped `.app` when a tag is pushed
- Homebrew cask
- Developer ID signing and notarization, so the Gatekeeper dance goes away

## Features
- Clipboard history
- Notch UI
- Shake-to-summon (shake the cursor while dragging to show the shelf)
- Multiple shelves
- Cloud sync / upload-and-share links
- Arrow-key navigation between cards
- Collect screenshots copied to the clipboard (⌃⌘⇧4), which never become files
